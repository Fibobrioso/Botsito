# docs/nocturno/

Registro de las sesiones autónomas nocturnas que pide Aleks por escrito: el plan con el que empieza
la noche, el informe con el que acaba y, si se agotan las funcionalidades desbloqueadas, el
inventario de lo que falta. Una sesión nocturna **nunca cierra**: no hace merge, tag ni push
(`CLAUDE.md`, «main no se toca»); deja la rama en su último commit verde y lo que necesita decisión,
anotado para la mañana.

- `PLAN-01oct.md` · qué funcionalidades se intentan la noche del 30 de septiembre al 1 de octubre de
  2026, en qué orden y con qué criterios de aceptación.
- `INFORME-01oct.md` · lo terminado, lo bloqueado, las decisiones de interpretación y las preguntas
  para Aleks. Se escribe al cerrar la noche.
